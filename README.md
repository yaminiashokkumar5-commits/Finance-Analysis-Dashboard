# Finance Analysis Dashboard | Power BI

## Project Overview
This project presents an interactive Finance Analysis Dashboard developed using Microsoft Power BI to analyze financial transactions, customer segments and transaction patterns.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Key Features
- Total Amount, Total Transactions and Average Transaction Value KPIs
- Monthly Transaction Trend Analysis
- Transaction Status Analysis
- Customer Segment Analysis
- State-wise Transaction Amount Analysis
- Transaction Type Analysis
- Gender-wise Transaction Analysis
- Year, Occupation and Merchant Category filters

## Business Insights
- Compare transaction volumes across months.
- Identify customer segments contributing to transaction value.
- Analyze transaction types, fees and taxes.
- Explore transaction distribution across states and customer groups.
